How to set up your CoveScapes start page

Follow these steps on a desktop or laptop. The pictures are simplified examples. Your ZIP or extracted folder may have your edition’s name.

Save and unzip · Open the page · Set your homepage

1. Save your download in a folder

  1. On your desktop, right-click an empty spot and select New → Folder on Windows or New Folder on Mac.
  2. Name it My Start Page.
  3. Save the CoveScapes ZIP in that folder. If it already went to Downloads, open Downloads in File Explorer or Finder and drag the ZIP into My Start Page.

2. Unzip the file

A ZIP is a package of files. Unzipping it creates regular files that your browser can open together.

Windows

  1. Open My Start Page and right-click the ZIP.
  2. Choose Extract All…. If you don’t see it, try Show more options.
  3. Click Browse, select Desktop → My Start Page, and click Extract.

Mac

  1. In Finder, open Desktop → My Start Page.
  2. Double-click the ZIP. Finder extracts its contents alongside the ZIP.
  3. If an edition-named folder appears, open it to find Desktop-Homepage.

3. Find and open index.html

  1. Open My Start Page, then open the extracted folder if there’s one named after your edition.
  2. Open Desktop-Homepage. The file is usually named index.html. It may display as index if your computer hides file extensions.
  3. Double-click it to open your default browser. To choose a different browser, right-click the file and use Open with.
  4. Leave index.html and the assets folder together. You should see the artwork, search box, and category cards.

4. Copy the address from your browser

With your CoveScapes page open, click the address bar at the top of the browser or press Ctrl + L on Windows or Command + L on Mac. Copy the entire address with Ctrl + C or Command + C. It normally starts with file:/// and ends with index.html.

5. Set your browser’s home or startup page

Open settings inside the browser you use. Paste the copied address with Ctrl + V on Windows or Command + V on Mac. A Home button opens your homepage on demand. A startup page opens when you launch the browser.

Google Chrome

Startup: ⋮ → Settings → On startup → Open a specific page or set of pages → Add a new page. Paste the address and select Add. For the Home button, go to Appearance, turn on Show Home button, and use the custom address option.

Chrome Help
Microsoft Edge

… → Settings → Start, home, and new tabs. Under When Edge starts, choose Open these pages and add the address. For one-click access, set the custom address under Home button and turn on the button if needed.

Microsoft Edge Support
Mozilla Firefox

☰ → Settings → Home. Under Homepage and new windows, choose Custom URLs and paste the address. If only your CoveScapes tab is open, you can also choose Use Current Page where available.

Firefox Help
Safari on Mac

Safari → Settings → General. Paste the address into Homepage or select Set to Current Page while your CoveScapes tab is open. Choose Homepage for New windows open with if you want it in new windows.

Safari Support

Try it: Click your browser’s Home button or fully quit and reopen it if you configured startup. If your browser rejects the local address or restores your old tabs, open the file from Desktop → My Start Page → Desktop-Homepage. On Windows you can right-click index.html and use Show more options → Send to → Desktop (create shortcut) where available. On Mac, right-click and choose Make Alias, then move the alias to your desktop. Keep the original files in their folder.

You’re set when you see your CoveScapes artwork

If artwork or buttons are missing, unzip the full package again and open the index.html beside the assets folder. Google searches and external websites require internet access.
