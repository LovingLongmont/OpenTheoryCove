Full setup and customization instructions
Getting started
Extract the ZIP completely and open index.html from the extracted desktop homepage folder in Chrome, Edge, or Firefox. Keep assets beside index.html.
Open it when your browser starts
In Chrome, go to Settings → On startup → Open a specific page or set of pages. In Edge, go to Settings → Start, home, and new tabs → When Edge starts. In Firefox, go to Settings → Home → Homepage and new windows → Custom URLs. Use the local page address where your browser accepts it. If it rejects the address, open the HTML file directly from a desktop shortcut. Replacing the new-tab page may require an extension.
Edit shortcuts
Use the quick-shortcut editor to change each name, address, and icon. In editions with the current editor, you can add up to 10 entries, reorder or delete them, or leave the list empty.
Organize categories and links
Use Edit links & categories to add, rename, reorder, hide, or delete categories where supported. Open a category’s website editor to add, search, edit, move, or delete links. If a deletion prompt appears for a populated category, choose how to handle its links.
Personalize the page
Use Settings to edit the title and other available header text. Hidden categories retain their links. Where available, Show all categories temporarily displays the whole collection.
Back up and restore
Open Backup & Restore and download a JSON backup. Save it outside the homepage folder. To restore it, select the backup file in a compatible edition and confirm replacing the current settings.
Move to another computer
Copy the whole extracted folder and your backup, open the page on the new computer, and restore the backup. Changes typically stay in that browser’s local storage. Clearing browser data or changing browsers can reset the page.
Use it offline
Local artwork, menus, editing, backups, and the clock where included work offline. Google searches and external links require internet access.
